<h2>🎯 The Problem</h2>
<ul>
<li><strong>30M+ daily-wage workers</strong> in Pakistan struggle to find consistent work daily</li>
<li>Clients <strong>2-3 hours</strong> finding reliable workers for urgent tasks</li>
<li><strong>Zero trust infrastructure</strong> — no verification, no escrow, no accountability</li>
<li>Existing platforms are not built for <strong>same-day urgency</strong></li>
</ul>
<h2>💡 Our Solution</h2>
<p><strong>Rozgaar</strong> is an AI-first mobile platform that enables:</p>
<ul>
<li>⚡ <strong>15-second job posting</strong> with predefined categories</li>
<li>🤖 <strong>AI-powered price estimation</strong> based on location, category &amp; historical data</li>
<li>🔒 <strong>Escrow payments</strong> via JazzCash/EasyPaisa</li>
<li>✅ <strong>Trust &amp; verification</strong> with CNIC, photo proof, and ratings</li>
<li>📍 <strong>Hyperlocal matching</strong> starting in Lahore neighborhoods</li>
</ul>
